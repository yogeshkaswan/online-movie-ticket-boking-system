# Online Movie Ticket Booking System

## Description
A Java-based application for booking movie tickets online.

## Features
- Movie search
- Theatre and show selection
- Seat selection
- Ticket booking
- Ticket cancellation
- Booking history

## Technologies Used
- Java
- OOP
- Collections Framework

## Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- ArrayList / HashMap
- Exception Handling

## How to Run
1. Clone the repository
2. Open the project in IntelliJ IDEA / Eclipse
3. Compile the Java files
4. Run Main.java
